# 턱없이

이동약자를 위한 마산 지역 길찾기 **시연용 프로토타입**입니다.
[웹사이트 열기](https://seoajeong98.github.io/-/)

경로, 지도, 버스, 자동차 시간, 충전소와 배터리 계수는 정적 샘플 또는 가정입니다. 실시간 API와 실제 지도가 연결되어 있지 않으며, 실제 통행 가능성·도착 시간·주행거리를 보장하지 않습니다. **실제 이동에 사용하지 마세요.**

## 실행

Python 3가 설치되어 있다면 저장소 루트에서 다음 명령을 실행하고 `http://localhost:8000/`을 엽니다.

```sh
python3 -m http.server 8000
```

설치하거나 설정할 API 키는 없습니다. 화면 스타일은 Tailwind CSS CDN을, 글꼴은 Google Fonts를 사용하므로 인터넷 연결이 필요합니다. 스타일을 불러오지 못하면 경고와 기본 화면을 표시합니다. 시연 데이터와 계산은 저장소에 포함되어 있으며 실시간 데이터로 전환되지 않습니다. 위치 조회는 HTTPS 또는 localhost의 브라우저에서만 이용할 수 있습니다.

## 주요 기능과 시연 방법

- **경로**: `시범1`에서 쉬운 길은 950m, 빠른 길은 780m입니다. 진입 불가 구간이 있는 후보를 제외하고, 미확인·주의 구간의 길이로 쉬운 길을 고릅니다. `시범2`는 다른 구간, `시범3`은 경로 데이터 없음, 출발·도착 전환은 역방향을 보여 줍니다. 선택한 이동기기의 가상 속도에 따라 시간이 달라집니다. 임의 장소 검색이나 실제 접근성 판정은 제공하지 않습니다.
- **버스·자동차**: 정류장을 바꾸면 샘플 도착 정보가 바뀝니다. 미연동 정류장은 데이터가 없다고 표시합니다. 자동차 토글은 시연값을 켜고 끄며 API를 호출하지 않습니다.
- **배터리·충전소**: 25km, 50%, 경사 계수 0.8을 입력하면 8.50km가 표시됩니다. 빈 값, 잔량 범위 밖 또는 0 초과~100km 범위 밖의 완충 주행거리는 오류로 표시합니다. 충전소도 샘플이며 거리와 운영 여부는 실제 정보가 아닙니다.
- **도움 요청**: 위치는 초기에는 미확인입니다. 버튼을 누른 뒤 브라우저 위치 권한에 동의하면 기기의 GPS를 조회합니다. 실패하면 오류를 표시하고 임의 좌표를 채우지 않습니다. 수동으로 고른 위치는 시연용이라고 명시합니다. 연락처가 유효할 때만 전화·문자 앱 링크가 활성화됩니다. 메시지는 초안이며 자동 발송되지 않습니다.

위치와 연락처는 이 페이지의 메모리에서만 사용하며 서버에 저장하거나 전송하지 않습니다. 전화·문자 앱 열기 또는 복사는 사용자의 명시적인 조작으로만 이루어집니다. 외부 CDN에는 페이지 접속에 따른 네트워크 요청이 전달됩니다. 추후 외부 API를 연결한다면 실패와 미연동 상태를 구분해 안내하고, 비밀 API 키는 브라우저 코드가 아닌 서버에서 관리해야 합니다.

## 코드 구성

| 경로 | 내용 |
| --- | --- |
| `index.html`, `assets/styles.css` | 화면 구조와 스타일 |
| `assets/data.js`, `assets/state.js` | 시연 데이터와 화면 상태 |
| `assets/logic.js` | 경로 후보 선정과 배터리 계산 |
| `assets/route-ui.js`, `transport-ui.js`, `battery-ui.js`, `help-ui.js`, `app.js` | 기능별 화면과 이벤트 |
| `tests/current-site.test.cjs` | 현재 사이트의 계산·검증·도움 요청 테스트 |
| `website/index.html` | 이전 공유 주소를 기본 사이트로 연결 |
| `previous/index.html`, `tests/prototype.test.cjs` | 이전 버전 및 해당 버전의 회귀 테스트 |

## 테스트

Node.js 18 이상이 설치되어 있다면 다음 명령으로 현재 사이트와 이전 버전의 테스트를 실행합니다.

```sh
node --test tests/*.test.cjs
```

현재 사이트 테스트는 경로 선택·진입 불가 제외·역방향·잘못된 입력·배터리 계산·위치 미확인과 연락처 검증을 확인합니다. 실제 GPS, 문자 발송, 외부 API, 현장 안전성은 검증하지 않습니다.
